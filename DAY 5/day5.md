PROMPT B (WITH CONTEXT)

Create a 30-day learning roadmap.

Context:
- Current Situation: [Student/Professional/Freelancer]
- Current Skills: [Add Skills]
- Goal: [Target Goal]
- Available Time: [Hours per Day]
- Experience Level: [Beginner/Intermediate]
- Preferred Learning Style: [Videos/Projects/Reading]

Include:
- Weekly milestones
- Daily tasks
- Resources
- Projects
- Final outcome

Make it practical and beginner-friendly.

Compare both outputs and identify:
1. Which roadmap feels more personalized?
   obviously the second one feels more personal as we provide details before the outputs
3. Which roadmap would you actually follow?
   2nd one
5. What role did context play in improving the result?
6. Context acts as the foundational map that turns raw data into a precise, useful answer. Without context, answers stay generic, miss the mark, or cause mistakes. Adding background details, goals, and constraints cuts down ambiguity and shapes the final output to fit real needs
